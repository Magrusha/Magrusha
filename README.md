## 1. Алгоритмы кластеризации
**Задача:** Обучение без учителя — кластеризация данных о нью-йоркской аренде (Kaggle, NYC rental listings).  
**Стек:** Python 3, NumPy, Pandas, Scikit-learn, Matplotlib.

**Ключевая реализация:**
- Ручная реализация K-means с нуля: инициализация центроидов, пересчёт центров, присвоение кластеров, критерий остановки по изменению центроидов.
- Реализация DBSCAN: параметризация радиуса окрестности и минимального числа соседей, выделение шума и выбросов.
- Выбор числа кластеров двумя эвристиками — методом локтя (distortion) и коэффициентом силуэта.
- Использование меток кластеров как нового признака в Lasso Regression с MinMaxScaler; интерпретация через веса модели.
- Сравнение с реализациями из sklearn для K-means, DBSCAN, AgglomerativeClustering и GaussianMixture (EM).
- Кластеризация на разных наборах признаков: географические координаты и комбинация bedrooms / bathrooms / interest_level.
- Разбор ограничений: K-means предполагает сферические кластеры и требует задавать k; DBSCAN плохо соединяет кластеры разной плотности; EM сходится к локальному оптимуму.
- Теоретическая часть: альтернативные схемы инициализации центроидов (Forgy, Random Partition) и ускорение KNN через кластеризацию и kd-tree.

## 2. Снижение размерности
**Задача:** Обучение без учителя — матричная факторизация и манифолд-обучение.  
**Стек:** Python 3, NumPy, SciPy, Pandas, Scikit-learn, UMAP-learn, разреженные матрицы, Matplotlib.

**Ключевая реализация:**
- Разбор и сравнение методов матричной факторизации: SVD, PCA, NMF; объяснение связи PCA и SVD и различий NMF и SVD.
- Манифолд-обучение: t-SNE, UMAP, Locally Linear Embedding; описание структуры LLE.
- Рекомендательная задача на Book Recommendation Dataset: разреженная матрица взаимодействий пользователь–книга, линейная модель и случайный лес для предсказания возраста, сжатие признаков через PCA и UMAP с сравнением времени обучения и качества.
- Визуализация MNIST: сжатие изображений цифр в 2D с помощью PCA, SVD, Randomized-SVD, t-SNE, UMAP, LLE и сравнение методов по качеству разделения классов.
- Сжатие изображений через SVD: вариация ранга, восстановление, анализ спектра сингулярных значений и объяснённой дисперсии.
- Обнаружение фона в видеопоследовательности (Background Models Challenge) через низкоранговое SVD-приближение.
- Разбор ограничений: t-SNE не сохраняет глобальную структуру и вычислительно дорог, UMAP быстрее и лучше сохраняет глобальную геометрию, LLE чувствителен к шуму.
- Теоретическая часть: проклятие размерности и его влияние на разные модели.

## 3. Многослойный перцептрон MLP
**Задача:** Бинарная классификация рисков на данных автомобильных аукционов (Kaggle: Don't Get Kicked).  
**Стек:** Python 3, NumPy, Pandas, Scikit-learn.

**Ключевая реализация:**
- Полная ручная реализация прямого и обратного распространения ошибки (backpropagation) без фреймворков.
- Математический вывод и программная реализация градиентов Log Loss для активаций Sigmoid, ReLU и Cosine.
- Реализация оптимизаторов SGD (с мини-батчами) и Adam с нуля.
- Строгое временное разделение выборки (`train < valid < test` по дате) для предотвращения утечки данных.
- Сравнение с `sklearn.MLPClassifier` и PyTorch с разбором причин расхождений (инициализация, адаптивный learning rate).

## 4. Сверточные нейронные сети CNN
**Задача:** Классификация жестов на основе датасета Zindi gesture data.  
**Стек:** Python 3, PyTorch, OpenCV, Albumentations, timm, Pandas.

**Ключевая реализация:**
- Кастомный класс `Dataset` для чтения изображений через OpenCV и `DataLoader` для пакетной загрузки.
- Ручная сборка LeNet-5 из слоёв `Conv2d`, `Pooling`, `Linear`, `Dropout`.
- Transfer Learning: дообучение бэкбонов (ResNet18 из `timm`) с адаптацией классификационной головы.
- Аугментации через Albumentations, программная реализация MixUp и CutMix.
- Test-Time-Augmentation (TTA) для усреднения предсказаний на этапе инференса.

## 5. Рекуррентные нейронные сети RNN
**Задача:** Генерация имён и классификация пола по последовательностям символов.  
**Стек:** Python 3, PyTorch, NumPy, Scikit-learn (PCA, t-SNE), Matplotlib.

**Ключевая реализация:**
- Ручная реализация блока Vanilla RNN (forward и backward pass) без готовых слоёв фреймворка.
- Стохастическая генерация последовательностей с управляемой температурой (temperature sampling).
- Анализ исчезающего градиента: сбор градиентов эмбеддинга через `register_backward_hook`, норма Фробениуса, сравнение затухания для RNN, GRU и LSTM.
- Многозадачное обучение: одновременная оптимизация потерь предсказания следующей буквы и классификации пола.
- Визуализация эмбеддингов букв через t-SNE и PCA с кластеризацией гласных и согласных.
